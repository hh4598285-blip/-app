# BattleMind

A polished offline Android tactical game prototype focused on combat, strategy and fast decision-making.

## Modes
- Tactical Arena — deploy units and manage energy.
- Brain Strike — pressure-style scoring mode.
- Commander Mode — high-score command sandbox.

## Build
Open with Android Studio or run `gradle assembleDebug` with Android SDK 35 and Java 17.

GitHub Actions automatically builds `app-debug.apk` on pushes to `main` and publishes it as the `BattleMind-APK` workflow artifact.
